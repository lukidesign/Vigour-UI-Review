安装与配对

Apple Silicon · beta.1 安装步骤

  1. 01

    下载并解压

    分别下载并解压 M 系列安装器与 beta.1 配套扩展。

  2. 02

    加载 Chrome 扩展

    打开 chrome://extensions，开启开发者模式，加载 chrome-extension 文件夹并复制 ID。

  3. 03

    安装并配对

    运行 Setup，填入实际扩展 ID，再从 Chrome 扩展打开工作台。

完整 Apple Silicon 安装指南

Intel Mac · beta.3 安装步骤

  1. 01

    下载并解压

    确认“关于本机”显示 Intel，完整解压核心版，保留 intel-stage 文件夹。

  2. 02

    加载包内扩展

    在 chrome://extensions 开启开发者模式，加载包内 chrome-extension，复制扩展 ID。

  3. 03

    安装并配对

    运行包内 Setup 并填写扩展 ID，打开工作台后使用“像素 + 结构分析”；此包不含 OCR。

完整 Intel Mac 安装指南

Windows · beta.2 安装步骤

  1. 01

    下载并解压

    完整解压 Windows beta.2 包，保留其中的安装器与扩展。

  2. 02

    加载 Chrome 扩展

    打开 chrome://extensions，开启开发者模式，加载包内 chrome-extension 文件夹并复制 ID。

  3. 03

    安装并配对

    运行 Setup，填入实际扩展 ID，再从 Chrome 扩展打开工作台。

完整 Windows 安装指南

请停用旧扩展，使用同平台、同次构建的配套文件；不要仅凭界面中的 0.0.2 判断是否匹配。

常见问题

反馈问题
为什么还要安装本地程序？
扩展负责采集网页，本地程序负责分析和工作台。两者需使用匹配版本并完成配对。
需要配置 Figma 或 AI 吗？
不需要。直接导入 PNG / JPG 即可分析，Figma 和 AI 都是可选功能。
数据会上传吗？
核心对比在本机完成。AI 外发逐次确认，图片默认不发送。数据处理与保存方式详见隐私说明 ↗
为什么各平台的 Beta 版本不同？
Apple Silicon 使用 beta.1，Windows 使用 beta.2，Intel Mac 核心版使用 beta.3。程序和扩展都显示 0.0.2，请以发布标签和包内构建记录区分，不跨平台或跨构建混用扩展。
支持手机或其他系统吗？
现有测试包面向 macOS Apple Silicon、Intel Mac 和 Windows x64；Intel 核心版不含本地 OCR。手机可浏览本页，安装和使用需在对应电脑上完成。
