## 测试前对抗式审查

已检查错误尺寸不能通过容错伪装成完整截图、新 ID 写入失败不能破坏旧配对、清理路径不能越界、项目数据不能被卸载删除、原始异常不能进入采集提示和报告文本不能生成恶意 HTML/链接。

审查补充修复了三个边界：数据库关联失败时不误报可分析；部分卸载后保留清理目标以便重试；死进程遗留锁与活跃锁分开处理。清理恢复仍采用保守策略，无法确认锁归属时停止，不强行删除。

## 本地验证

- `pnpm release:check` 通过：仓库检查、商店素材静态检查、类型检查、165 项 JS/TS 测试、生产构建、27 项 Python 测试、合成视觉基准。
- 合成基准：50 组、500 个标注差异、500 匹配。它不代表真实网页准确率，也未验证文字抗锯齿误报。
- 拼接测试覆盖 DPR 1/1.25/1.5/1.3875、1/3/10 段；检查连续行与右边缘像素保留，并拒绝尺寸变化、缺口和负坐标。
- Windows 安装核心测试使用临时目录和模拟注册表；覆盖新 ID 修复、失败回退、重复卸载、清理中断、伪造路径、死/活进程锁和数据保留。**运行主机为 macOS，不是 Windows GUI 验收。**
- 隔离浏览器检查用真实 API、Python 拼接引擎和构建后的工作台，另注入可控故障。验证失败禁用、处理中、刷新恢复、Escape 关闭、深浅主题及 1920/1440/900/720 宽度下采集弹窗的排版。未连接用户数据库、未修改系统配对、不占用 4179 端口。
- 构建仍有已有大体积 JS bundle 警告，Python 提示缺少 ccache；不影响本轮命令完成，不代表已优化性能。

隔离浏览器回归入口：设置与[截图脚本相同的两个浏览器环境变量](../scripts/README.md)，执行 `pnpm exec tsx scripts/smoke-capture-recovery.ts`。当前脚本使用 macOS/Linux 风格的视觉引擎虚拟环境入口，不能直接作为 Windows 真机脚本。

## 新 Windows 候选包必测

1. 在 Windows 构建环境从确定提交重新生成安装器、扩展与校验和；记录源码提交，不能只替换扩展。
2. 普通账号交互式安装；填入实际扩展 ID，从 Chrome 工具栏连接，不手改任何配置。
3. 同一实例分别测视口、单段整页、3 段与 10 段长页。覆盖 100%/125%/150% 和原报告 DPR；核对右边缘、接缝、底部，不只看接口成功。
4. 改用另一个有效扩展 ID，执行“修复 Chrome 配对”；确认新 ID 可连接、旧 ID 不再授权，并验证失败时旧配置可恢复。
5. 测交互卸载与静默卸载：记录进程退出码、总时间、程序与 Setup 目录、注册表、项目数据；关闭 Chrome 后重试失败清理，再重装检查项目保留。
6. 如卸载再次卡住，保留 Inno `/LOG` 日志，以及 `%LOCALAPPDATA%\Programs\Vigour UI Review Setup\installer\diagnostic.json` 和 `result.txt`（成功清理后这些文件可能已移除）。诊断仅记录动作、阶段、耗时与安全错误码；发送前仍需检查日志并移除个人路径等信息。不要发送令牌、密钥或整个用户数据目录。
7. 导出同批次 Markdown/PNG/JSON，核对证据链接与坐标；另测真正断网、睡眠恢复及连续采集。

未纳入本次：安装 12 分钟耗时优化、文字误报算法、圆角检测、真实断网 OCR、签名/公证或 Chrome Web Store 审核。商店素材检查通过不等于审核通过。发布与真机验证要求继续遵循[Windows 内测状态](WINDOWS-BETA-STATUS.md)和[发布流程](RELEASING.md)。
