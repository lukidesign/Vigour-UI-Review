# Vigour UI Review 安全模型

## 支持版本与漏洞报告

当前只为最新的 `0.0.x` 版本提供安全修复。请在 GitHub 仓库的 **Security → Report a vulnerability** 中使用 Private Vulnerability Reporting；不要通过公开 Issue 提交漏洞、访问令牌、私有设计稿或客户数据。

## 信任边界

- 服务仅绑定 `127.0.0.1`，不监听局域网。
- 除下述一次性票据交换和 CORS 预检外，所有 `/api/` 请求需要 256 位会话令牌；写请求额外要求 CSRF Header。
- CORS 只允许本地工作台和已配对 Chrome 插件来源，预检请求不携带凭据。
- 扩展来源必须配置完整的 32 位 ID；拒绝 `chrome-extension://*`、远程网站、`null` 和空 Origin。无 Origin 的本地客户端仍必须提供 Token/CSRF。
- 插件只在用户发起采集后注入脚本；不常驻所有网页、不申请 `tabs` 权限。采集入口只接受本扩展 popup 的消息。
- 一次只允许一个采集；绑定 tab/window/document，页面切换、导航、尺寸变化时中止，截图前后再次校验。页面清理有独立 20 秒看门狗，防止 worker 中断后遗留临时样式。
- 上传阶段不能保证服务端回滚，因此禁用取消；结果不确定时提示检查“最近采集”，不宣称截图已丢弃。
- 应用数据目录权限为 `0700`，令牌、图片和证据文件为 `0600`。
- 文件路径由服务生成；Python JSON-RPC 再次校验路径必须位于应用数据根目录。

## Native Messaging（未发布源码）

- Rust 启动器只调用同包 Node 和固定脚本，不使用 shell 或用户 PATH，并去掉 Node 注入选项。
- Chrome 清单和 Host 同时校验精确扩展 ID。协议只接受 `protocol: 1, command: connect`，不接受任意命令、URL、路径或截图。
- 消息上限 16 KiB，严格 UTF-8、长度前缀和请求字段；主机 stdout 只输出协议，不记录令牌或页面数据。
- 启动使用私有锁及实例身份验证；遇到不属于自身的 4179 服务拒绝连接，不终止其进程。恢复锁本身异常时保守超时，后续安装器需提供修复流程。
- 成功绑定端口后才轮换令牌，磁盘原子写入且权限为 `0600`。浏览器不永久保存令牌；Native 端口仅在启动/连接期间保活，成功或超时后关闭。
- `POST /api/v1/session/exchange` 是唯一无需 Token/CSRF 的数据 API：只允许配置中的本地工作台 Origin，并校验 256 位随机票据。票据 60 秒过期、只能消费一次，错误返回不含凭据；相关响应禁止缓存。
- 工作台在任何异步操作前从 URL 删除票据。旧 `#token` 入口仅作为开发兼容保留，不用于新扩展打开工作台。
- 服务任务和工作台租约阻止空闲退出；扩展定时器只报告已连接服务的标签状态，不会自动启动服务。
- 此机制防止网页/未授权扩展访问，不试图隔离拥有同一操作系统账号权限的恶意本地程序。Native 安装配置、日志和数据目录仍须依赖操作系统文件权限保护。

## 输入限制

- 单图最多 25 MB、4,000 万像素；PNG/JPEG 依据文件签名识别。
- 单次采集最多 100 段、25 MB；DOM 最多 20,000 节点。
- Figma JSON 最多 20 MB、20,000 节点；渲染下载拒绝私网地址和重定向。
- AI 请求和响应均有供应商能力、载荷、超时与 Schema 限制。

## 密钥

Figma PAT 和四家 AI Key 只保存在 macOS 钥匙串。保存密钥时通过 `security -i` 的 stdin 传入，避免出现在进程参数；服务错误只返回白名单错误码。

## AI 外发

AI 关闭时核心功能完全离线。每次调用由供应商、模型、任务、问题集合和图片选择共同生成 SHA-256 载荷哈希；同意回执只能使用一次。问题文字被明确标记为不可信证据，模型输出必须通过本地 Zod Schema，且不会自动改代码或问题状态。

## 已验证攻击面

- localhost 跨站、Origin 欺骗、无 Token/无 CSRF 写入。
- 路径穿越、符号链接、伪造 MIME、图片尺寸欺骗、超大响应。
- 非法任务状态迁移、并发状态更新、失败落盘残留。
- Figma 私网下载和错误泄漏。
- AI 同意回执重放、载荷调换、提示注入、非视觉模型图片上传。
