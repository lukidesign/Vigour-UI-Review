# Vigour UI Review 安全模型

## 支持版本与漏洞报告

当前只为最新的 `0.0.x` 版本提供安全修复。请在 GitHub 仓库的 **Security → Report a vulnerability** 中使用 Private Vulnerability Reporting；不要通过公开 Issue 提交漏洞、访问令牌、私有设计稿或客户数据。

## 信任边界

- 服务仅绑定 `127.0.0.1`，不监听局域网。
- 所有 `/api/` 请求需要 256 位会话令牌；写请求额外要求 CSRF Header。
- CORS 只允许本地工作台和已配对 Chrome 插件来源，预检请求不携带凭据。
- 应用数据目录权限为 `0700`，令牌、图片和证据文件为 `0600`。
- 文件路径由服务生成；Python JSON-RPC 再次校验路径必须位于应用数据根目录。

## 输入限制

- 单图最多 25 MB、4,000 万像素；PNG/JPEG 依据文件签名识别。
- 单次采集最多 100 段、25 MB；DOM 最多 20,000 节点。
- Figma JSON 最多 20 MB、20,000 节点；渲染下载拒绝私网地址和重定向。
- AI 请求和响应均有供应商能力、载荷、超时与 Schema 限制。

## 密钥

Figma PAT 和四家 AI Key 只保存在 macOS 钥匙串。保存密钥时通过 `security -i` 的 stdin 传入，避免出现在进程参数；服务错误只返回白名单错误码。

## AI 外发

AI 关闭时核心功能完全离线。每次调用由供应商、模型、任务、问题集合和图片选择共同生成 SHA-256 载荷哈希；同意回执只能使用一次。问题文字被明确标记为不可信证据，模型输出必须通过本地 Zod Schema，且不会自动改代码或问题状态。

## 已验证攻击面

- localhost 跨站、Origin 欺骗、无 Token/无 CSRF 写入。
- 路径穿越、符号链接、伪造 MIME、图片尺寸欺骗、超大响应。
- 非法任务状态迁移、并发状态更新、失败落盘残留。
- Figma 私网下载和错误泄漏。
- AI 同意回执重放、载荷调换、提示注入、非视觉模型图片上传。
