# 阶段 B：Native Messaging 按需启动

日期：2026-09-16。状态：核心源码和隔离联调已完成；未发布、未改写实际 Chrome 注册，图形安装器尚未交付。

## 目标

用户打开扩展后启动或复用本地服务，通过一次性票据打开工作台，不需要日常打开终端或复制令牌。保留现有工作台三栏布局及主题，不在本阶段扩张视觉、AI 或跨平台范围。

## 实现

- `apps/native-host/launcher.rs`：无外部 crate 的轻量启动器，调用包内 Node，不经 shell。当前只编译并验证 Apple Silicon。
- `apps/native-host/*.mjs`：受限 stdio 控制协议、精确来源校验、启动互斥、健康及实例验证、私有状态与日志。
- `apps/chrome-extension/src/native-client.ts`：短时 `connectNative` 连接、友好错误、会话存储、工作台票据及后台标签心跳；连接完成即关闭 Native 端口。
- `apps/local-service/src/local-session.ts`：单次 60 秒票据、令牌轮换协作、任务计数、页面/标签租约、15 分钟空闲退出判断及休眠恢复宽限。
- 工作台：票据先移除再交换；令牌只放标签页会话；连接失败引导从扩展重新打开，手动入口折叠为开发调试。
- 开发命令：`build:native`、`test:native`、`scripts/register-native.mjs`；开发包复制 Native 模块，但尚不是完整用户安装器。

## 对抗式审查与修正

在测试前审查了非授权来源、异常协议、并发启动、端口被占、旧会话重放、标签冻结和冷启动后台回收等路径：

1. 超大消息在 Buffer 拼接前拒绝，字段白名单禁止任意命令执行。
2. 死进程启动锁回收串行化，防止两个等待者误删彼此新锁；异常恢复锁保守超时。
3. 连接校验服务身份、协议、私有实例文件及令牌，不能将其他本地程序误认为自身。
4. 新服务绑定失败不得覆盖当前令牌；服务重启后旧令牌立即失效。
5. 慢到达的旧心跳失败不能清除新会话。
6. 空标签心跳不刷新活跃时间；后台页面保持租约，休眠恢复给心跳留宽限。
7. 冷启动使用 `connectNative` 明确保活，成功/失败/65 秒超时后关闭，避免永久占用后台。
8. 正常入口不再要求用户找令牌；失效票据移出地址栏并展示恢复指引。
9. 票据申请声明 JSON 类型时显式发送空 JSON 对象，避免真实 Fastify 拒绝空请求体；开发启动等待改为绝对截止时间。

## 验证结果

- 全工作区类型检查、生产构建、仓库检查通过。
- TypeScript/JavaScript：24 个文件、110 项测试通过；较阶段 A 增加 26 项。
- Python：11 项通过。
- 合成基准：50 对图、500 处差异通过；不代表真实网页检测准确率。
- 本机 Rust 编译通过；使用临时工具链，未修改全局 PATH。
- `pnpm test:native` 通过：真实 Rust → 包内 Node → HTTP 服务 → Python 引擎；拒绝非法来源和命令、保留无关端口进程、并发单实例、一次性票据/重放、重启轮换、死锁文件回收。
- 测试注册写入临时目录，不写入用户 Chrome；临时服务正常退出，测试包和数据已清理。
- 独立 Chrome for Testing 中验证 1920×1080 工作台：真实票据交换后自动进入、无手动令牌弹窗、无横向溢出和浏览器运行错误；过期票据显示恢复指引，手动令牌输入默认折叠。已查看两种状态截图；等待弹窗动画完成后截取，避免把动画前一帧当作视觉证据。
- 空闲时间、活动请求和休眠恢复使用可控时钟测试；尚未做真实 15 分钟、多窗口/休眠持续观察。
