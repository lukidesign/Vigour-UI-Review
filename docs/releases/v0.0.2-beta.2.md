## 下载与安装

在 [beta.2 发布页](https://github.com/lukidesign/Vigour-UI-Review/releases/tag/v0.0.2-beta.2) 的 Assets 下载实际列出的附件：

- `Vigour-UI-Review-v0.0.2-beta.2-windows-x64-unsigned.zip`：完整 Windows 测试包，含 Setup EXE、同次构建扩展、入门说明、复测清单和内部校验和。
- `Vigour-UI-Review-extension-v0.0.2-beta.2-windows.zip`：同一 Windows 构建的扩展副本；完整 ZIP 已包含它，无需重复下载。不要与 Mac beta.1 配套程序混用。
- `SHA256SUMS.txt` 和 `BUILD-PROVENANCE.json`：附件校验和及源码/构建来源。

完整解压，在 Chrome 加载包内 `chrome-extension`，复制实际扩展 ID，停用旧扩展，再双击 `Vigour-UI-Review-0.0.2-windows-x64-dev-setup.exe` 安装/更新并填写该 ID。从工具栏打开工作台，无需手改三处配置或复制 token。

不要关闭 Defender、SmartScreen 或组织安全策略。若安装被拦截，停止并反馈。使用公开合成或已获许可的测试页面，不发送令牌、密钥、客户原图或完整用户数据目录。

## 修复与复测重点

1. 非整数 DPR 下的整页拼接；请分别测单段、3 段、10 段、不同系统缩放和浏览器缩放，检查右边缘、接缝及底部。
2. 保存处理状态和安全错误原因；不可分析的截图不再误报成功，最近采集支持刷新与恢复指引。
3. “修复 Chrome 配对”使用新 ID，可回退旧配置；普通用户无需手改配置。
4. 卸载退出、清理重试、死进程锁恢复与阶段日志；**原先超过 9 分钟卡住尚未在 Windows 11 验证解决**。
5. Markdown 补充问题 ID、坐标、建议和 PNG 证据引用；需将同批次另行导出的 PNG 放在报告同目录。

## 验证边界

本地发布检查通过 165 项 JS/TS、27 项 Python、类型检查、生产构建和 50 对/500 处合成差异基准；隔离浏览器覆盖真实拼接、状态反馈、深浅主题与 720–1920 宽度的采集弹窗。合成结果不是实际网站准确率结论。

发布附件只采用通过 CI 的 Windows 构建；准确提交和运行号见随包来源记录。Windows Server 2022 构建、整包校验、离线核心分析、Native/凭据烟测和 Inno 编译不能替代 Windows 11 普通用户电脑验收。

继续保留：Windows 11 交互安装、真实 Chrome 流程、升级/卸载、系统缩放、空闲/睡眠恢复、整机断网及 OCR；签名、真实页面误报、安装耗时优化和圆角检测。商店审核也没有保证。
