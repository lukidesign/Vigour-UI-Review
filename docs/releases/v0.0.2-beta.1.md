## 本次更新

- 项目栏默认收起，优化走查、缩放、主题按钮与标题；导出入口移到问题清单。
- 三种比较模式均显示标注，支持统一隐藏/显示和问题定位。
- AI 问题解释与组件业务逻辑推断共用弹窗，保留不同任务说明/结果结构与每次发送确认；修复确认消费及异步范围变化边界。
- Native 按需启动、一次性配对和当前用户图形安装/修复/回退/保留数据卸载。
- 安全补丁依赖、匹配 0.0.2 扩展与双平台测试包。

## 已有证据与未完成事项

macOS 核心程序构建自 `5b457fbfa11370c946b56ddf550942d1a133daf7`；本次安装助手重新构建，部署目标及 Info.plist 最低版本统一为 14.0。实际构建提交、CI 运行号和附件 SHA-256 随 `BUILD-PROVENANCE.json` 提供；不得把核心程序原有测试当作新包装已通过相同全流程实测。

2026-10-19 集成版通过 135 项 JS/TS、11 项 Python、构建、生产依赖审计及 50 对/500 处合成差异基准。macOS 重建核心包通过整包、离线核心分析、隔离 Native/安装器测试；维护者 Mac 的真实 Chrome 视口/整页采集、分析、三种标注模式及三种导出通过。这些不是干净机器或最低 macOS 的验收结论。

**Windows 11 真机测试：待完成。** Windows 包仅有 Windows Server 2022 CI 构建、整包/许可证校验、离线核心分析、凭据/Native 协议烟测和安装器编译证据；普通 Windows 11 账号安装、真实 Chrome 采集导出、缩放、休眠恢复、升级/卸载、用户目录权限仍需验证。
