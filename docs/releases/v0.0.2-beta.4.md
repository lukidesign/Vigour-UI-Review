# v0.0.2-beta.4 · Apple Silicon 未签名测试更新

面向 **macOS 14.5+ M 系列 Mac** 的独立预发布，程序与扩展版本仍为 **0.0.2**。**未签名、未公证；本次真实 Chrome、干净机、最低系统、空闲/睡眠和离线 OCR 验收待完成。** 不设为 Latest，不替换 beta.1、Windows beta.2 或 Intel beta.3 附件。

最低系统调整：保留 OCR 所需的 Paddle 二进制声明 macOS 14.5，因此本包不支持 14.0–14.4；安装器系统声明、编译目标和构建校验保持一致。Intel 无 OCR 包仍要求 macOS 14.0+。不以修改二进制声明的方式绕过依赖要求，也不将 CI 通过视为最低系统真机验收。

## 相对 Apple Silicon beta.1 的变化

- 整页拼接兼容非整数 DPR 的像素取整偏差，保留实际像素及尺寸/覆盖校验。
- 采集处理状态持久化，显示安全错误原因，不能分析的截图不误报成功。
- Markdown 包含问题 ID、坐标、期望/实际、需人工确认的建议以及同批 PNG 证据链接。
- 按实际引擎能力报告 OCR，保留 Apple Silicon 的 PaddleOCR 依赖配置；不等于离线模型已经准备好。

## 验证边界与升级

原生 arm64 CI 检查源码、完整包、架构/最低部署目标、核心分析、OCR 依赖加载和隔离 Native/安装生命周期；使用校验和锁定的公开 beta.1 包验证升级后的合成项目、采集、分析结果和证据保留。每次构建的结果及源码以发布附件来源记录为准，CI 不代替普通用户验收。

升级会增加采集状态数据库字段，提前备份数据；只验证相同数据库结构的安装器回退，不保证直接降级 beta.1。测试不修改维护者的真实 Chrome 注册或钥匙串，不外发 AI/Figma 请求。Windows 11 复测与 Intel 用户真机验收仍待完成。合成基准不代表真实网站准确率，GitHub 发布不等于 Chrome Web Store 批准。
