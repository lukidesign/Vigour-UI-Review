## 安装、功能和生命周期

- [ ] 无需关闭系统安全保护即可安装；记录未签名提示或阻断，禁止绕过组织策略。
- [ ] 使用实际提交的商店扩展 ID 配对，而不是只测试本地解压 ID。
- [ ] 工具栏启动 → 视口/整页采集 → 最近采集 → 分析 → 三模式标注 → PNG/Markdown/JSON 导出完整通过。
- [ ] 连续 20 次采集，逐次记录成功/失败；无错页、重复提交、崩溃或数据丢失。
- [ ] 取消、导航、切页、缩放和窗口变化安全停止，恢复页面；提交阶段不能取消的说明清楚。
- [ ] 不同 DPR、长页、固定元素、懒加载、横向滚动均有实际结果和已知限制。
- [ ] 后台/最小化不误退出；真实空闲等待、Chrome 重启、服务重启、休眠恢复后可重新连接。
- [ ] 安装/更新/同结构回退/修复/卸载不误删项目或凭据，不覆盖其他 Native 注册，不终止不属于自己的端口进程。
- [ ] 活动任务阻止不安全更新；macOS 废纸篓行为、Windows 程序移除及锁定文件残留分别验收。
- [ ] 1920×1080、1440 宽度及 Windows 100%/125%/150% 缩放；另记录窄屏问题，不据此宣称全尺寸适配。
- [ ] 核心离线分析和 OCR 离线单独记录；缺模型提示可理解，不误称完全离线。

## 隐私、权限和安全

- [ ] 打开弹窗仅连接程序，不主动采集；捕获前显著说明目的、接收方和数据范围，并取得明确同意。
- [ ] 视口截图与 DOM/文字范围一致披露；处理 [READINESS.md](READINESS.md) 中的视口外收集问题，不能靠文档掩盖过度收集。
- [ ] 正常、失败和取消路径无错页泄露；无后台浏览历史、Cookie、密码库或键盘记录。
- [ ] 最终 ZIP 权限与 [PRIVACY-FIELDS.md](PRIVACY-FIELDS.md) 一致；全部扩展执行代码随包提供。
- [ ] 解决项目数据静态保护风险并验证 Windows 实际 ACL；不把 chmod 意图当 Windows 权限证据。
- [ ] 无效/过期令牌、票据重放、错误来源被拒绝；令牌不进入日志/报告，浏览器和本地凭据存储位置准确披露。
- [ ] 两种 AI 任务分别检查：未确认不发送，变更范围/重复请求/过期需重确认；完整图片范围明确，密钥可删除，返回文本不作为代码执行。
- [ ] Figma、AI 用授权测试账号完成实际请求，验证失败路径；记录提供商/模型和费用边界，不上传密钥。
- [ ] 英中隐私政策、详情、后台数据分类和实际包一致；公开政策不需登录，Limited Use 承诺可找到。
- [ ] 用系统工具验证彻底删除本应用数据/凭据的指引；卸载保留数据不等于删除完成。
- [ ] 当前版本截图与可复现录屏使用公开合成数据，不包含客户信息或误导性界面。
