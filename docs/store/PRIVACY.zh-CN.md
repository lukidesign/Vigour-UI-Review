# Vigour UI Review 隐私说明

发布商名称与工程版权署名：LukiDesign。更新：2026-09-16。本稿说明 Native 内测源码，提交前须发布并与最终包复核；旧包可能仍采用手动令牌流程。

## 数据与用途

主动点击采集后，扩展处理所选网页的截图、完整 URL、标题、文字、位置、计算样式、视口/DPR 和滚动信息，用于 UI 验收。整页采集临时滚动、调整动画，结束或异常时尝试恢复。工作台还保存设计图、项目、验收历史、问题和证据。

截图及 URL 可能含个人信息、机密或敏感查询参数；当前不是自动脱敏工具，请先隐藏不想采集的内容。不申请 Chrome 历史库、Cookie 或密码管理器，不记录键盘输入历史。

## 本地和外部连接

- 默认通过带会话认证的本机地址 `127.0.0.1:4179` 连接配套程序，不上传到开发者服务器。
- 数据位于 `~/Library/Application Support/Vigour UI Review/`；文件权限不等于整个数据库加密。
- 新扩展凭据在 `chrome.storage.session`，工作台凭据在标签页 `sessionStorage`。URL 单次票据交换前移除。成功启动轮换令牌，新版成功连接后清理旧扩展长期保存的令牌。
- 只检查本地工作台标签状态以决定空闲退出，不持续读取其它标签页；代码没有产品统计、广告或开发者数据接收服务。
- Figma 导入向 Figma 发送选定文件/节点和认证信息；可选 AI 只发送本次确认的上下文和可选图片，逐次授权，回执十分钟过期且不可重放。
- Figma PAT、AI Key 保存在 macOS 钥匙串，不设计写入项目数据库、日志或导出。
- OCR 缺少模型时可能首次下载；模型可用后本地推理，不保证所有功能首次即完全离线。

外部 API 使用 HTTPS，本机传输在同一电脑内完成。第三方按其政策及你的账号设置处理数据。日志可能含技术错误和本地路径，报告可能含页面内容，分享前需检查。

## 保留、删除与联系

数据保留至主动移除，不承诺自动过期。关闭标签或卸载扩展不会清除本地项目。安装助手升级、回退和卸载时保留数据与钥匙串；历史迁移可能保留旧副本。彻底删除前请停止服务、备份，再用 macOS 工具移除自己的数据及钥匙串。已导出/外发的数据不因卸载自动删除。见 [安装说明](../INSTALL.md)。

数据只用于公开说明的设计验收功能，不售卖、不用于广告、信贷或贷款资格判断。正常使用不向开发者提供本地数据，用户主动提交的支持材料除外。

支持：[GitHub Issues](https://github.com/lukidesign/Vigour-UI-Review/issues)。不要公开客户资料、凭据和私有截图。安全问题优先使用仓库私密报告，不可用时先请求私密联系方式，不公开敏感证据。
