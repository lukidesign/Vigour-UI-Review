## 数据与用途

本产品用于用户主动发起的网页采集和设计图对比。

- **打开扩展弹窗**会启动或重新连接已配对的本地程序，交换连接/会话信息，不会自动采集网页。连接后定期将匹配的本地工作台标签 ID 告知配套程序，用于空闲管理，不读取其他标签内容。
- **点击采集**后，处理所选页面截图、完整 URL（可能含查询参数和片段）、标题、文字、元素位置、计算样式、视口、设备缩放、页面尺寸、滚动位置和采集时间。
- **范围限制**：视口模式只限制截图，不限制全部 DOM 采集。两种模式都会检查 body 下最多前 20,000 个后代元素，保留满足条件的元素及叶子文字，每段最多 2,000 字符；可能包括视口外元素，不是“仅选中组件”采集。
- 采集临时调整动画样式，整页模式会滚动；完成或中断后尝试恢复样式和滚动位置。
- 工作台保存导入图片、主动导入的 Figma 元数据、项目、验收历史、问题、评分、证据及授权回执，用于分析、历史查看和导出。

截图、文字和 URL 可能含个人信息、通信内容、财务/健康信息、可见凭据或机密。**当前不自动脱敏。**请用合成或已授权数据；仅隐藏画面信息不能保证相关 DOM 文字和 URL 不被采集。扩展不申请读取 Chrome 历史数据库、Cookie 库或密码管理器，不记录键盘输入历史。

## 本地存储与安全

采集数据经带会话认证和来源检查的 `http://127.0.0.1:4179` 发给同一电脑上的程序，不上传到开发者服务器；回环连接不使用 TLS。Native Messaging 负责启动/会话控制，截图和 DOM 走本机 HTTP 接口。

| 平台 | 默认运行数据 | 可选 Figma/AI 凭据 |
| --- | --- | --- |
| macOS Apple Silicon | `~/Library/Application Support/Vigour UI Review/` | macOS 钥匙串 |
| Windows x64 | `%LOCALAPPDATA%\Vigour UI Review\` | Windows 凭据管理器 |

项目数据库、截图、导出及诊断文件**没有应用层静态加密**。文件权限与系统保护不等于项目数据已加密；Windows 用户访问控制仍需真机复验。

扩展当前连接凭据存于 `chrome.storage.session`，工作台存于标签页 `sessionStorage`；配套程序还在数据目录写入本地 `session-token` 文件，请勿分享。工作台打开票据短时、单次有效，交换前从地址移除。服务启动轮换令牌，新版成功连接后清除旧扩展本地存储的长期令牌。

Figma PAT 与 AI Key 经系统凭据设施保存，不设计写入项目数据库、报告或日志。诊断文件可能含技术错误和本地路径。代码没有产品统计、广告 SDK 或开发者运营的验收数据接收服务。

## 可选联网和接收方

本地像素分析不需要 Figma 或 AI；保存 API Key 本身不授权外发验收内容。

| 用户操作 | 接收方及数据 |
| --- | --- |
| 导入 Figma Frame | 向 Figma HTTPS API 发送 PAT 和所选文件/节点标识；下载设计元数据和 Figma 返回的 HTTPS 地址上的图片。 |
| AI 问题解释或组件业务逻辑推断 | 向选定服务商发送结构化问题上下文：验收标识/结果、描述、位置、期望/实际值及已有 CSS 建议。明确勾选且支持时，还发送**完整标注证据图**，不限于当前组件。 |
| OCR 初始化缺少模型 | 向模型下载服务发起下载请求，包含通常的网络信息；推理设计为本地执行，不保证首次或断网 OCR 可用。 |
| 打开下载、支持或服务商链接 | GitHub 或对应网站接收访问，适用其政策。 |

AI 接收方为 OpenAI（`api.openai.com`）、Google Gemini（`generativelanguage.googleapis.com`）、Kimi/Moonshot（`api.moonshot.cn`）或 DeepSeek（`api.deepseek.com`），使用 HTTPS 及对应凭据。当前 OpenAI/Gemini 支持图片，Kimi/DeepSeek 适配器不支持。每次请求需对服务商、模型、任务、上下文/图片选项确认；回执十分钟过期、仅使用一次，范围改变或重试需重新确认。

AI 输出用于人工复核，不是已证实业务事实，也不会自动执行生成代码。第三方保留期限、人工访问、训练、处理地域和费用取决于其条款及账户设置，本产品不承诺零保留或不用于训练，请在确认前核查。正常使用不会把验收数据发给开发者；导出可能含页面内容，由你决定是否分享。

## 保留与删除

项目、图片、采集和回执不承诺自动到期删除。关闭工作台、移除扩展或卸载配套程序不会清除这些数据；升级与卸载保留项目及系统凭据。macOS 旧版迁移可能在 `~/Library/Application Support/Design Acceptance 2.0/` 留下恢复副本。

彻底移除前先停止/卸载程序、备份需要的内容，再用系统文件管理器删除**本应用自己的**数据目录，另行清除对应凭据：

- macOS 钥匙串服务：`com.vigour-ui-review.local`；旧版可能还有 `com.design-acceptance.local`。
- Windows 凭据管理器中的本应用普通凭据：以 `com.vigour-ui-review.local/` 开头。
- 账户为 `figma-pat`、`ai-openai`、`ai-gemini`、`ai-kimi`、`ai-deepseek`，不要删除其他应用条目。

Chrome 扩展需单独移除。macOS 将管理的配套程序移入废纸篓；Windows 删除管理的程序目录，文件占用时可能残留已解除注册的目录。以上不删除导出、备份、数据目录外的 OCR 缓存或已发给服务商/支持渠道的副本，需分别处理；不确定路径时先求助，不要删除大范围目录。见[安装与卸载说明](../INSTALL.md)。
