# 阶段 C：图形安装与商店材料

状态：执行中的内测增量 SPEC。日期：2026-09-16。承接阶段 A/B；原产品 SPEC 中不做商店发布的 MVP 边界由本增量计划扩展，但本轮不直接发布。

## Problem Statement

Native 启动链路已可在隔离环境工作，但普通用户仍缺少图形安装、扩展 ID 配对、修复及回退入口。上架素材缺失，文案与真实的数据处理行为需要统一。

## Proposed Solution

- Apple Silicon 原生安装助手，用户确认后安装到自己的 Application Support，不需要管理员权限。
- 支持明确扩展 ID 配对、原目录修复、上一安装版本回退、保留用户数据的卸载。按版本保留程序，更新不覆盖正在使用的文件。
- 严格验证安装包、路径与现有注册的归属；遇到非本程序服务或注册时停止，不接管。
- 生成中英文商店文案、权限理由、隐私说明、审核步骤、测试表、图标、宣传图及真实演示截图。缺少商店 ID、发布链接或目标机验收时明确标记。

## Technical Constraints

- 继续使用现有 Node/Python 服务和 Rust Native 启动器；安装界面使用系统原生控件，沿用 VR 品牌，不引入桌面 WebView。
- 当前只验证本机 Apple Silicon；未签名开发包不能标成正式签名安装包，不关闭系统安全策略。
- 本次测试只操作临时目录和隔离服务，不修改实际 Chrome 配置、已安装程序或用户数据库。
- 图标延伸现有 VR 标识，用矢量源生成各尺寸，不使用虚构产品画面替代截图。

## Non-goals

- 不发布 GitHub Release、不提交商店、不购买开发者账号或证书。
- 不做云端账号、遥测、后台自动更新、Intel/Windows 安装器，不宣称它们已支持。
- 不把构建成功等同于新机器安装、真实 Chrome 工具栏采集或上架审核通过。

## Success Criteria

- 安装/更新/修复/回退/卸载均有边界测试；错误不覆盖外部注册、不删除项目和钥匙串、不杀无关进程。
- 安装助手可编译成 .app；隔离副本完整运行 Native 服务。
- 商店草稿和本地数据、外部调用、功能限制一致；素材尺寸校验通过且人工查看。
- 保留三栏和主题；1920×1080 工作台截图来自实际运行结果。
- 每个开发阶段先对抗式审查，再跑回归，未通过的交付门槛保留为待办。
