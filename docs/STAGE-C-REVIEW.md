日期：2026-09-16。源码版本仍为 0.0.1，未发布、未覆盖旧下载包。承接 [SPEC](spec/STAGE-C-SPEC.md)。

## 本轮交付

- AppKit 图形安装助手：安装/更新、精确 ID 配对、修复、回退上一安装、保留数据卸载。
- 按文件 SHA-256 校验、内部相对链接检查、版本目录、归属标记、安装/启动互斥；仅停止经过实例和路径验证的服务。
- 服务关闭接口继续要求身份验证和 CSRF；活动请求阻止更新，不向任意 PID 发信号。
- 离线包使用冻结的 Python 依赖与哈希校验，并补充 Rust 标准库许可。
- 中英文商店文案、隐私政策、权限/数据字段、审核指引、内测表、4 个图标、2 张宣传图和 3 张实际工作台截图。
- 按 UI/UX 与 AntDV 规范保持三栏和现有主题，修复平铺宽度翻倍、放大后左边不可达的问题，并为缩放按钮补充可访问名称。

## 测试前对抗式审查

| 反例 | 处理与证据 |
| --- | --- |
| 包文件被替换、混入私人配置或外部链接 | 安装前和复制后再次校验，拒绝异常包；单测覆盖 |
| 目标为符号链接、未知目录或其他 Native 注册 | 验证路径与归属，不接管；单测覆盖 |
| 4179 为别的服务或仍有分析 | 实例 ID、安装根目录与身份验证匹配才请求关闭；忙则退出 |
| 更新与 Native 启动同时发生 | 两把互斥锁；不抢占活动锁，崩溃恢复体验仍待完善 |
| 卸载误删项目或凭据 | 管理程序移入废纸篓，独立数据目录与钥匙串不删除 |
| 截图借用客户页面、伪造分析结果 | 仅公开示例通过实际引擎生成；记录来源，未用截图冒充工具栏端到端证据 |
| 仅检查页面总宽，漏掉画布左端裁切 | 人工看图发现，新增图像边界与 200% 放大滚动断言后重新截图 |

## 已完成验证

- `pnpm release:check`：121 项 JS/TS 测试、11 项 Python 测试、类型检查与构建通过。
- 图像基准：50 对、500 个标注差异通过。这是合成基线，不能宣传为真实页面 100% 准确。
- Native 隔离测试：精确来源、未知命令、端口占用、并发单实例、票据重放、令牌轮换、失效锁恢复通过。
- `pnpm package:check`：15,664 个文件，约 1.04 GB；无绝对链接与构建机器路径泄露。
- `pnpm package:smoke`：实际离线包上传示例图片、调用本地分析并生成 10 个问题及证据图通过；没有使用源码虚拟环境替代包内引擎。
- 安装助手 Swift 编译通过；实际窗口排版查看与空 ID 拦截通过，未在真实用户目录执行安装。
- 商店素材规格校验通过，图标/两张宣传图/三种真实视图人工查看。
- 1920×1080、1440 宽度的桌面结构检查通过；1280×800 商店截图通过。900、720 宽度不通过，原有最小桌面宽度尚未消除，不宣称移动适配完成。
- 完整离线安装/更新/回退/卸载集成通过：使用真实打包的 Rust/Node/Python，在隔离用户目录完成安装、启动、身份验证关闭、更新、令牌轮换、同结构回退、修复、运行中卸载；确认测试项目文件仍保留且程序进入隔离废纸篓。

## 不能据此宣布上架就绪

1. 真实 Chrome 工具栏授予 activeTab → Native 启动 → 采集 → 分析/导出闭环，以及后台、休眠和实际空闲退出仍需内测。
2. 新 Mac 下载后隔离属性/Gatekeeper、正式签名、公证、最低 macOS 版本仍未验收；Windows/Intel 不在本轮支持范围。
3. 回退只验证同数据库结构；断电、磁盘写满、安装锁恢复与失败事务的系统级故障注入仍需完善。
4. 需新版本号、真实商店 ID、匹配下载 URL/校验值、公开最新隐私 URL、账号资料与测试名单。
5. 支持入口暂拟 GitHub Issues，未虚构邮箱。没有上传、提交商店、GitHub push 或修改现有安装。

本轮使用临时程序和数据验证；清理的仅是脚本创建的测试目录，不是用户项目。当前开发安装包约 1 GB，不属于商店 ZIP，商店只上传扩展文件。

商店材料已独立归档在 `release-artifacts/Vigour-UI-Review-store-materials-stage-c-20260916.zip`，附 SHA-256，ZIP 完整性检查通过。它只含文档和素材，不能作为扩展安装 ZIP 上传。
