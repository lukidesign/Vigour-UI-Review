# 视觉参考与授权

浏览器展示框的形式参考 [Magic UI / Safari](https://github.com/magicuidesign/magicui/blob/main/apps/www/registry/magicui/safari.tsx)。本页以原生 HTML/CSS 重写，未安装或分发其 React 组件。为保留参考来源，附上所查看仓库的 MIT 授权文本。

Studio 仪表盘两版 SVG、导入叠图与报告插图为本项目原创。Vigour 标识沿用本仓库素材，工作台和问题列表来自本项目实际运行截图。未使用 Screenshot.rocks 输出素材，也未集成 Motion。
